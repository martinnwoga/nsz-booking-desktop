# NSZ Booking for Mac and Windows

Download the latest version from the **Releases** page on the right.

- **Mac:** open the `.dmg`, drag NSZ Booking into Applications. The first time, right click the app and choose **Open** (it isn't signed by Apple yet).
- **Windows:** run the `.exe`. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

The app opens https://nsz-booking-lilac.vercel.app and adds screen sharing with a picker and its own icon.
